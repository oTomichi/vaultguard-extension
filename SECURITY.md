# Reporting a security issue

If you find a way for this extension to leak data, be tricked into a wrong score, or be abused by a page, please report it.

- **Sensitive (exploitable) issues:** use the support contact on the Chrome Web Store listing
  (https://chromewebstore.google.com/detail/imadlfaempmcofkekgjinkcbhddkpnmg) rather than a public issue.
- **Everything else** — false positives, missed threats, confusing warnings: open a GitHub issue.
  Include the contract address or domain and what the overlay showed. Missed threats are the most
  valuable reports we get.

Scope: this repository is the extension only. The scoring API is a separate, private service.
